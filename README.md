Разрабатываю клиентские и серверные приложения более 6 лет. Работаю с **Java, Vert.x, Spring, TypeScript и React**. Проектирую backend-сервисы, REST API и структуру баз данных, разрабатываю пользовательские интерфейсы.

Есть опыт разработки CMS, e-commerce систем, VK Mini Apps, Telegram Mini Apps и интеграций с их API.

## Опыт
- Backend разработка на Java с использованием Spring и Vert.x
- Frontend разработка на TypeScript, React и Next.js
- Верстка интерфейсов по макетам с Figma
- Проектирование REST API и работа с PostgreSQL, MySQL и MongoDB
- Разрабатываю плагины для Bukkit, Nukkit и PocketMine-MP. Владелец [NewPlugin](https://vk.com/newplugin) — сообщество разработчиков с аудиторией более **10 000 участников**.
